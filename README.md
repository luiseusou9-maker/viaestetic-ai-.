# 🩺 Viaestetic AI-Stock Analyzer

Protótipo de Inteligência Artificial desenvolvido para otimização de estoque e gestão de validades em distribuidoras de materiais médico-hospitalares.

## 🚀 Sobre o Projeto
Este sistema utiliza **IA Generativa** para analisar dados de estoque da **Viaestetic**, identificando automaticamente produtos próximos ao vencimento e SKUs com estoque crítico. O objetivo é garantir o compliance com as normas da **ANVISA** e evitar perdas financeiras por expiração de produtos de alto valor (ex: toxinas e preenchedores).

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python 3.10+
- **Engine de IA:** [Groq Cloud](https://groq.com) (Modelo Llama 3 8B)
- **Interface:** [Streamlit](https://streamlit.io)
- **Análise de Dados:** Pandas
- **Hospedagem:** Streamlit Community Cloud

## 💡 Funcionalidades
- **Monitoramento de Validades:** Alerta automático para produtos que vencem em 30 dias.
- **Chat Logístico IA:** Interface em linguagem natural para consultas complexas sobre o inventário.
- **Análise de Risco:** Identificação de produtos de alto custo com baixa rotatividade.
